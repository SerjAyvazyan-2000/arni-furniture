# Мебель Анри — Краснодар

Одностраничный продающий сайт фабрики мебели «Мебель Анри»: кухни на заказ, спальный гарнитур «Ирис», портфолио, калькулятор кухни, квиз-расчёт, cookie-баннер, пользовательское соглашение и политика конфиденциальности.

## Структура

```
index.html
assets/
  images/   фото работ и логотип
  css/      style.css
  js/       main.js
```

Открыть локально: двойной клик по `index.html`.

Сайт разработан в студии [Сайтика](https://studio-psi-olive.vercel.app/).
